# fix5-sweep-result.md — springStiffnessScale 校准结论

日期：2026-08-06（fix5 轮 1，Step 2）

## 方法

- 脚本：`packages/mmd_tool/scripts/fix5-sweep-scale.mjs`
- **用真实 bake-physics.mjs 扫描**（不用 diag-chest2 简化模型 —— 已验证其与真实 bake 分歧巨大，scale=2000 时 diag 报 23° 但真实 bake 267°，因为缺 angleLimitation IK）。
- 每个 scale 独立进程 + 独立临时 config（`output/fix5-tmp-scale-N.json`），禁止累积式修改（fix4 diag-solver4 污染教训）。
- 测左胸上/右胸上 f45/f75 角度（quaternion 幅角 2·acos(w)），errSum = Σ|ours − MMM|。
- 两轮：第一轮 damping=0.05（纯 stiffness 影响）；第二轮 damping=0.85（最终 config，含 ERP/CFM 锁定轴）。

## 结论

1. **最优 scale = 1000**。判定依据（按方案 Step 2 完成标准优先级）：
   - **fix5 接受判据 = 左胸上 f75 ≤ 50°**。scale=1000 得 45.9° ✔（266.9° → 45.9°，降 82.8%）。
   - scale=500 errSum 略低（337 vs 354.7）但**不满足接受判据**（左胸上 f75=84.6° > 50°）——其低 errSum 靠右胸上/裙子补偿，属 zone 差异，不是整体对齐。
   - scale=2000（旧）左胸上 f75=267.2°，为最差之一；scale=5000 全面发散。
   - 方案预期「最优 10-40°」：scale=1000 得 45.9°，接近区间上沿（MMM 本身 f75=5.7° 极保守，符合预期）。
2. **damping 0.05 → 0.85 方向正确**：同一 scale=1000，damping 0.85 把左胸上 f45 50.4→41.4、f75 30.7→45.9（右胸 f45 66.4→150.4 属 zone 回归，见下）。
3. **裙子假设被推翻**：スカート_0_1 f45≈33-37° 在所有 scale（500~5000）基本不变，且远小于 MMM（约 96°+，f45 参考）。→ stiffness ÷scale **不是**裙子幅度偏小的驱动因素；裙子需走 **Step 4 zone rules**（分区域调参），本轮不改。
4. **右胸上/zone 差异**：右胸上 f45 在 scale=1000 出现 150.4° 尖峰（MMM=7.7°），且随 scale 无单调规律 → 属 zone 级问题，Step 4 处理。全骨 median 角差 32.56°（verify 实测），仍在可接受范围。

## 落地

- `bake-config.json`：`springStiffnessScale: 2000 → 1000`、`springDamping: 0.05 → 0.85`。
- bake-physics.mjs 注释同步更新（÷1000 + fix5 sweep 数据 + 明确「起身段偏前发、胸部偏胸骨，不同最优」）。
